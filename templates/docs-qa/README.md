# Docs Q and A

Answers questions about your documentation in chat or Slack and links the pages it used.

## What it needs
- A model provider key (Anthropic by default).
- For Slack: secrets `SLACK_SIGNING_SECRET` and `SLACK_BOT_TOKEN`.

## How it starts
- Chat: ask a question in the test pane.
- Slack: mention the bot in a channel it was added to.

## Before you turn it on
- Replace `[YOUR PRODUCT]` and `[YOUR DOCS URL]` in the instructions.
