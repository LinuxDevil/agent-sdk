# invoice-extract — accounts-payable invoice pipeline

**Scenario.** An AP team receives vendor invoices as text (email bodies, OCR output) and PDFs. Each
document is extracted to a strict schema, checked against business rules (line items sum to the
subtotal, tax math, total math, due date after issue date), and routed: clean invoices under
USD 1,000 are scheduled automatically. Everything else (over the threshold, or flagged) waits for a
human approval through the SDK's approvals. Quotes and other non-invoices are rejected. The batch
ends with `out/invoices.csv`, an accuracy report against hand-written ground truth, and token usage.

## SDK features exercised

| Feature | Where |
| --- | --- |
| Structured output (`output:` zod 4 schema: discriminated unions, enums, nullable/optional, money as regex strings, nested arrays, `.describe()`), repair step, `outputError` | `schema.ts`, `pipeline.ts` (`makeExtractor`), `repro/live-schema.ts`, `repro/schema-wire.ts` |
| Flows: `FlowBuilder` + `FlowExecutor` with `toolCall`, `oneOf` and the safe expression language | `pipeline.ts` (`apFlow`), `repro/flow-*.ts` |
| Approvals: a `needsApproval` predicate over server-side data, `agent.approvals.list()/resolve()` | `pipeline.ts` (`makePayments`), `index.ts` (review) |
| `withRetry` (custom `retryOn`, backoff, `onRetry`) + `withFallback` (Responses API, then Chat Completions via `fromAiSdk`) | `pipeline.ts` (`makeProvider`), `repro/fallback-concurrency.ts` |
| Multimodal `file` parts (a real PDF) | `fixtures/makePdf.ts`, `repro/pdf-file-part.ts` |
| Per-run `AbortSignal` (`send(x, { signal })`), bounded concurrency over a shared agent | `index.ts`, `repro/shared-agent-concurrency.ts` |
| Reasoning model behaviour (leakage, `result.reasoning`, `reasoning` option) | `repro/reasoning.ts`, `repro/reasoning-budget.ts` |
| Usage aggregation across the batch | `index.ts` |

## Fixtures

`fixtures/` holds 15 text documents and 1 real PDF (`inv-16-summit-pdf.pdf`, generated by
`fixtures/makePdf.ts`). They cover USD/EUR/AED/GBP; US, European, ISO and spelled-out date formats;
German, French, Dutch and Arabic documents; a discount; two OCR-damaged scans; a vendor arithmetic error
(line items do not add up); a wrong VAT amount; a quotation (not an invoice); a GBP invoice under 1,000
GBP but over USD 1,000; and an invoice of exactly USD 1,000.00 (the boundary). `fixtures/groundTruth.ts`
has the expected fields, flags and route for each one.

## Run

```bash
cd audit
npx tsx invoice-extract/fixtures/makePdf.ts                 # (re)build the PDF fixture
npx tsx invoice-extract/index.ts --concurrency 2 --timeout 600000
npx tsx invoice-extract/index.ts --only inv-01,inv-16        # a subset
npx tsc --noEmit -p .                                        # typings (incl. repro/typing.ts)
```

Needs LM Studio at `http://localhost:1234/v1` (see `../_shared/local.ts`). Repros that use no model:
`repro/schema-wire.ts`, `flow-semantics.ts`, `flow-inputs.ts`, `fallback-concurrency.ts`,
`shared-agent-concurrency.ts`, `error-body.ts`. The others call the local model.
`repro/proxy.ts` is a logging proxy that the live repros use to show the exact wire requests.

Outputs go to `out/` (`invoices.csv`, `run-*.json`, repro transcripts). See `RUN_LOG.md` and `FINDINGS.md`.
